## 📱 Générer le QR Code pour la Carte

### Option 1: En Ligne (Rapide)

1. Allez sur https://www.qr-code-generator.com/
2. Entrez votre URL Vercel: `https://votre-site.vercel.app`
3. Personnalisez:
   - Couleur: Bleu (#2563EB) ou Vert (#10B981)
   - Taille: Grande (pour lisibilité)
   - Format: PNG haute résolution
4. Téléchargez
5. Envoyez à l'imprimeur

### Option 2: Avec Python

```python
import qrcode

# Votre URL Vercel
url = "https://votre-site.vercel.app"

qr = qrcode.QRCode(
    version=1,
    error_correction=qrcode.constants.ERROR_CORRECT_H,
    box_size=15,
    border=4,
)

qr.add_data(url)
qr.make(fit=True)

# Couleur bleue
img = qr.make_image(fill_color="#2563EB", back_color="white")
img.save("qr_code_carte_visite.png")

print("✅ QR Code généré: qr_code_carte_visite.png")
```
